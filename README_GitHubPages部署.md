# 昆虫成长观察挑战营官网 - GitHub Pages部署说明

## 当前成品

本目录是一个纯静态网站，可以直接放到 GitHub Pages 托管。

入口文件：

```text
index.html
```

## 推荐部署方式

1. 在 GitHub 新建公开仓库，例如：

```text
insect-growth-camp
```

2. 把 `site` 目录里的全部文件推送到仓库根目录。

3. 在仓库设置里打开：

```text
Settings -> Pages -> Build and deployment -> Deploy from a branch
```

4. 发布源选择：

```text
main / root
```

5. 保存后等待 GitHub Pages 自动生成访问地址。

## 上线前必须替换

- 报名二维码图片
- 微信号或表单链接
- 首期城市和线下沙龙地点
- 活体昆虫来源和领取方式
- 真实团队姓名与资质表述

## 目前刻意没有做的事

- 没有接入在线支付。
- 没有收集孩子隐私数据。
- 没有承诺心理治疗或保证效果。
- 没有全国寄送活体昆虫。

这些是为了让首版可以先低成本、低风险地上线验证。
